# キャラ個別カスタマイズ

## 操作

- キャラ管理タブでキャラを検索して選択します。
- キャラごとに基本レベル、プラス値、形態、本能・超本能の設定を行います。
- 空欄の項目は変更しません。
- レベル上限や形態・本能の非対応は実行時にキャラごとに検証し、対象外はログに表示します。

## データ保護

- 選択したキャラ以外のレベル・形態・本能は変更しません。
- 解放対象は既存の図鑑掲載判定とエラーキャラ除外を通します。
- 指定レベルがキャラ固有上限を超える場合、値を丸めずそのキャラの処理を失敗として報告します。
- 実装後は `python -m unittest test_cat_customization.py` を実行し、さらに既存の全セルフテストを実行します。

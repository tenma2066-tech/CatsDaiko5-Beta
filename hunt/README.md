# 彩狩 -IROGARI-（ミニゲーム）

5色のハンターで大型モンスターを狩る、1〜5人の協力ターン制バトル。お店の VPS で `/hunt/` に置く。
名前・モンスター・絵はすべてオリジナル（絵はコードで組み立てた 3D）。

## いまできること（段階2）

- 1人でも、合言葉の部屋・公開の部屋（すぐ入る）でも遊べる。ハンター5人を、いる人数で順番に分けて操作する。
- 速さで行動順が決まるターン制。ターンが変わるたびに「〇〇 のターン！！」の帯が走る。
- 属性: 赤→緑→青→赤 の三すくみと、黄⇔紫 の相互有利（有利 ×1.3 / 不利 ×0.75）。
- 動作の種類: 選べるのは 通常攻撃 / アビリティ / 必殺技 / 奥義。選べないのは セットアビリティ（いつも効いている）と 条件アビリティ（条件を満たすと自動で発動）。
- 状態: 攻撃力上昇・低下 / 鈍足 / 停止 / 毒（最大体力の割合）/ 妨害無効 / 守り / 引きつけ / 防御低下。
- モンスター3体（★1〜3）。部位破壊、怒り、予告つきの大技。
- ログイン（ユーザー名＋パスワード）。ゲストでも遊べる。ログインすると戦績・実績・彩石（報酬）が残る。
  パスワードは scrypt のハッシュだけを保存する。セッションもハッシュで保存し、サーバーを入れ直してもログインが続く。
- 表示は 3D だけ（2D 表示はやめた）。キャラとモンスターはコードで組んだトゥーン調のモデル（ふちどりつき）。
- エフェクト: 斬撃・弾・衝撃波・火花、会心（星形の光・画面の光・カメラの寄り）、ガードの障壁、
  妨害ごとの演出（毒の泡・鈍足の輪・停止のかご・攻撃力の矢印）、かかっている状態はまわりを回る光の玉で見える。奥義は帯のカットイン。

## まだないもの（次の段階）

- ガチャ、素材・装備づくり、ハンターを選ぶ／増やす、モンスターの追加、ランキング。
- 絵や外部の 3D モデルは使っていない。差し替えるときは `index.html` の `buildHunter` / `buildMonster` を置き換える。
- お店のトップのメニューにはまだ出していない（URL を直接開く）。

## 作り

| ファイル | 役目 |
|---|---|
| `engine.js` | 戦いのルール。サーバーだけが持つ（ブラウザには結果だけ送る）。乱数は種から作るのでテストできる |
| `server.js` | HTTP と WebSocket（依存ゼロ）。部屋・持ち時間・乱用対策 |
| `accounts.js` | アカウント・戦績・実績・彩石。`HUNT_DATA_DIR/accounts.json` に保存 |
| `index.html` | 画面。Three.js r128（cdnjs）で 3D、DOM で UI と 2D 表示 |
| `test_engine.js` | `node test_engine.js` でルールのテストと、自動対戦でのバランス確認 |

動かす: `node server.js` → http://localhost:8080/
環境変数: `PORT` / `HUNT_DATA_DIR`（保存先）/ `HUNT_TURN_MS`（持ち時間）/ `HUNT_OFFLINE_MS`（切断中の人の番を待つ時間）

## 確認したこと（2026-11-28・段階2）

- `node test_engine.js`: 16 件（動作の種類、条件アビリティ3種を追加）。
- サーバーの結合テスト（生の WebSocket）: 部屋・割りふり・時間切れ・引き継ぎ・再接続。
- アカウントの結合テスト: 登録、入力の検査、重複、間違ったパスワード、セッションで戻る、ログアウト、
  勝つと彩石、実績の達成と受け取り、二重受け取りの拒否、保存ファイルに元のパスワードとセッションが無いこと、試しすぎの制限。
  サーバーを入れ直しても、アカウントが残ること。
- Chromium: 新規登録 → 1人で最後まで → 結果に報酬と実績 → 実績の受け取り → 開き直してもログインが続く。
  iPhone 13 の画面、2つのブラウザで交代に操作。ページのエラーなし。
- バランスは自動対戦での目安だけ。実際に遊んでの調整はまだ。

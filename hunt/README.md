# 彩狩 -IROGARI-（ミニゲーム）

5色のハンターで大型モンスターを狩る、1〜5人の協力ターン制バトル。お店の VPS で `/hunt/` に置く。
名前・モンスター・絵はすべてオリジナル（絵はコードで組み立てた 3D）。

## いまできること（段階1）

- 1人でも、合言葉の部屋・公開の部屋（すぐ入る）でも遊べる。ハンター5人を、いる人数で順番に分けて操作する。
- 速さで行動順が決まるターン制。画面の左（スマホは上）に行動順が出る。
- 属性: 赤→緑→青→赤 の三すくみと、黄⇔紫 の相互有利（有利 ×1.3 / 不利 ×0.75）。
- 技のタイプ: 物理 / 特殊 / 防御 / 回復・治療 / 妨害。各ハンターは 通常技・技2つ・奥義。
- 状態: 攻撃力上昇・低下 / 鈍足（ターンが回ってきにくい）/ 停止 / 毒（最大体力の割合）/ 妨害無効 / 守り / 引きつけ / 防御低下。
- 回復: 自分の最大体力の割合（シオン）、自分の攻撃力の割合で味方を回復（ミナモ）。
- モンスター3体（★1〜3）。部位破壊（1ターン停止＋防御低下）、怒り、予告つきの大技。
- 3D 表示と 2D 表示を画面のボタンで切り替え（選んだ表示はブラウザが覚える）。
- 持ち時間 40 秒（切れたら自動で通常攻撃）。切断しても同じ戦いに戻れる。抜けた人のハンターは残った人が引き継ぐ。

## まだないもの（次の段階）

- 素材・装備づくり・セーブ、ハンターを選ぶ／増やす、モンスターの追加、ランキング。
- お店のトップのメニューにはまだ出していない（URL を直接開く）。

## 作り

| ファイル | 役目 |
|---|---|
| `engine.js` | 戦いのルール。サーバーだけが持つ（ブラウザには結果だけ送る）。乱数は種から作るのでテストできる |
| `server.js` | HTTP と WebSocket（依存ゼロ）。部屋・持ち時間・乱用対策 |
| `index.html` | 画面。Three.js r128（cdnjs）で 3D、DOM で UI と 2D 表示 |
| `test_engine.js` | `node test_engine.js` でルールのテストと、自動対戦でのバランス確認 |

動かす: `node server.js` → http://localhost:8080/
環境変数: `PORT` / `HUNT_TURN_MS`（持ち時間）/ `HUNT_OFFLINE_MS`（切断中の人の番を待つ時間）

## 確認したこと（2026-11-28）

- `node test_engine.js`: 13 件。属性、鈍足、停止、毒、妨害無効、回復の計算、部位破壊、引きつけ、予告、同じ種なら同じ結果。
- サーバーの結合テスト（生の WebSocket）: 1人で最後まで、2人の割りふり、他人の番は断る、時間切れの自動行動、抜けた人の引き継ぎ、再接続。
- Chromium: 1人で最後まで遊んで結果画面まで、3D/2D の切り替え、iPhone 13 の画面、2つのブラウザで交代に操作。
- バランスは自動対戦での目安だけ（うまく遊ぶと3体とも勝てる。通常攻撃だけだと★2・★3は勝てない）。実際に遊んでの調整はまだ。

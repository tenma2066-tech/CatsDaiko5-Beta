# 彩狩 -IROGARI-（ミニゲーム）

5色のハンターで大型モンスターを狩る、1〜5人の協力ターン制バトル。お店の VPS で `/hunt/` に置く。
名前・モンスター・絵はすべてオリジナル（絵はコードで組み立てた 3D）。

## いまできること（段階3）

- 起動するとまずホーム画面（出撃・協力プレイ・編成・ガチャ・キャラ・実績）。ゲストでもログインでも、いきなり狩りには出ない。
- キャラ16人・3レア: R 5人（はじめから持っている・少し弱め）、SR 6人、UR 5人。ゲストは R だけ使える。
  キャラごとに 移動マス数 と 技ごとの射程 がある。同じキャラを重ねると体力・攻撃力 +4%（最大+4）。
- 戦場は 12×10 マス。自分の番は「動く（1回）→ 技 か 待機」。足元のマスで表示:
  青 = 動ける範囲 / 橙 = 選んだ技の射程（味方向けは黄）/ 赤い点滅 = 敵の大技の予告（そこから出ればよける）。
- いまの番: 光の柱と矢印・足元のマス・左上の「NOW TURN」・次の6人の順番・カードの持ち上げ・「〇〇 のターン！！」の帯。
- 必殺技・奥義（ボスの大技も）はカメラが回り込む演出（ため → 肩ごし → 当たる、上下の黒帯と技名）。そのあいだは撃つ人と相手だけを映す。
- AUTO ボタンで自分のキャラをオートに（サーバーの AI が動く）。×2 で演出を速く。スマホは戦場をドラッグで見回せる。
- ステージ: 第一章 始まりの草原 1-1〜1-5（1-5 はボス）と、特別討伐 EX1・EX2。前のステージをクリアすると次が開く。
- ガチャ（ログイン時）: 常設「彩の祈り」、ピックアップ3種（紅月の剣聖・蒼天と翠嵐・雷と紫電）、1回だけの半額「はじめての10連」。
  確率 UR 3% / SR 19% / R 78%。10連は10回目 SR 以上確定。70回で UR 確定（ピックアップがあればピックアップ）。
  抽選はサーバーの crypto 乱数。重ねきったキャラは彩石に戻る。新規登録で彩石 3,000、1日1回のログインボーナス 300。
- 協力: 部屋を作る / すぐ入る / 合言葉。5つの席をいる人で順番に分け、それぞれ自分の編成のキャラを出す。
- 段階2までのもの（属性のすくみ、状態異常、部位破壊・怒り、条件アビリティ、ログイン、実績）はそのまま。

## まだないもの（次の段階）

- 第二章以降のステージ、素材・装備、ランキング。キャラの立ち絵（いまはカードに頭文字）。
- お店のトップのメニューにはまだ出していない（URL を直接開く）。

## 作り

| ファイル | 役目 |
|---|---|
| `engine.js` | 戦いのルール。サーバーだけが持つ（ブラウザには結果だけ送る）。乱数は種から作るのでテストできる |
| `server.js` | HTTP と WebSocket（依存ゼロ）。部屋・持ち時間・乱用対策 |
| `accounts.js` | アカウント・戦績・実績・彩石。`HUNT_DATA_DIR/accounts.json` に保存 |
| `gacha.js` | ガチャの中身と抽選（確率・天井・ピックアップ） |
| `index.html` | 画面。Three.js r128（cdnjs）で 3D、DOM で UI |
| `test_engine.js` | `node test_engine.js` でルールのテストと、自動対戦でのバランス確認 |

動かす: `node server.js` → http://localhost:8080/
環境変数: `PORT` / `HUNT_DATA_DIR`（保存先）/ `HUNT_TURN_MS`（持ち時間）/ `HUNT_OFFLINE_MS`（切断中の人の番を待つ時間）/ `HUNT_AUTO_MS`・`HUNT_EVENT_MS`（オートの間合い）/ `HUNT_SCALE`（敵の強さの調整用）

## 確認したこと（2026-11-28・段階3）

- `node test_engine.js`: 16 件（移動範囲・射程・予告マスをよける・重ね など）と、オート同士の勝率表。
  目安: R だけで 1-1〜1-4 は 9割以上、1-5 は 7割前後、EX は難しい。SR を混ぜると EX1 も届く。UR 5人はどこも勝てる。
- サーバーの結合テスト（生の WebSocket）: ゲストは R だけの編成・EX は開かない、移動、オートで最後まで、
  新規登録 → はじめての10連（2回目は断る）→ ピックアップ単発 → 編成 → 1-2 は 1-1 クリア前は開かない → 1-1 クリアで初回報酬 → もう一度、
  2人の部屋で席の割りふり（01010）とオートで最後まで。2回続けて全部通過。
- Chromium（PC 1366×768 と iPhone 13）: タイトル → ホーム → キャラ一覧・詳細 → ステージ → 戦い（射程表示・必殺の演出）→ 結果、
  新規登録 → ガチャ10連 → 編成。ページのエラーなし。
- バランスは自動対戦での目安だけ。実際に遊んでの調整はまだ。

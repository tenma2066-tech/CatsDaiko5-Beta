# チンチロ 本格サイコロ賭場

3Dの丼とサイコロを物理演算で転がす、ブラウザで遊べるチンチロのゲームです。
`index.html` ひとつで動きます。インストールは要りません。

## 遊び方

1. `index.html` をブラウザ（Chrome / Safari / Edge / Firefox）で開く
2. タイトル画面でモードを選ぶ
3. 最初に画面をタップすると音が鳴るようになります

ネット接続がなくても遊べます。ネット接続がない場合は、見出し用の書体がふつうの書体に替わります。

### 投げ方

- **ボタン**：「振る」ボタンを長押しすると、ゲージが往復します。好きな位置で離すと、その強さで投げます。
- **スワイプ**：茶碗の上を指で上へ払っても投げられます。速く払うほど強く投げます。
- **キーボード**：スペースキーを長押しして離すと投げます。
- ゲージ右端の赤い部分は強すぎる範囲です。サイが丼の外に飛び出しやすくなります（ションベン）。

### 視点の操作

- ドラッグ：視点を回す
- ピンチ／マウスホイール：寄る・引く
- 右上の「視点」ボタン：標準・真上・低めを切り替える

## モード

| モード | 内容 |
|---|---|
| チュートリアル | 投げ方、役、親と子の配当を、実際に振りながら覚える。最後に役当てクイズ（5問） |
| 本格モード | あなたとCPU3人（慎重なタケ・強気のリュウ・気まぐれミヨ）で親を回して勝負。最後にチップの多い人の勝ち |
| 超デッドヒート | 宿敵カゲトラと1対1で全10局。局が進むほどレートが上がり、最終局は全賭け。1,000以上負けている側は勝った時の受け取りが1.5倍（逆転レート）。同点ならサドンデス。投げるたびに心音とスローモーションが入る |
| イカサマ見破り | 胴元が時々、4・5・6しかない細工サイを混ぜてくる。視点を回して側面を見るか「サイを改める」（2回まで）で確かめ、見抜けば賭け金の5倍を受け取る。外れ（いいがかり）なら3倍払い |
| 確率ラボ | 役の理論確率、今のルールでの子の期待値、物理演算で200回振った実測結果を見比べる |

そのほかに、役一覧、戦績・実績（16種類）、設定があります。

## 役と配当（初期設定）

| 役 | 出目 | 配当 |
|---|---|---|
| ピンゾロ | 1・1・1 | 5倍 |
| ゾロ目（アラシ） | 同じ数が3つ | 3倍 |
| シゴロ | 4・5・6 | 2倍 |
| 目 | 2つ揃い＋残り1つの数（1〜6） | 1倍 |
| 目なし | 上のどれでもない | 振り直し（3投まで。3投とも目なしなら負け） |
| ヒフミ | 1・2・3 | 2倍払い |
| ションベン | サイが丼の外に出る | 即負け |

- 強さの順：ピンゾロ ＞ ゾロ目 ＞ シゴロ ＞ 6の目 … 1の目 ＞ 目なし・ションベン ＞ ヒフミ
- 親がシゴロ以上・ヒフミ・目なし・ションベンを出した時点で、子は振らずに決着します。
- 親が「目」を出したら、子が1人ずつ振って親の目と比べます。同じ目なら分けです。

## 設定でできること

- ハウスルール：ピンゾロの倍率（5倍／3倍）、ヒフミの払い（2倍／1倍）、ションベンの扱い（即負け／1投消費して振り直し）
- 本格モード：最初の持ち金（5千／1万／3万）、局数（親が1〜3周）
- 演出：効果音のオン・オフ、演出の強さ（派手／控えめ）、CPUの手番の早送り

設定と戦績はブラウザの中に保存されます。ブラウザのデータを消すと、設定と戦績も消えます。

## 仕組み

- **物理演算**：外部のライブラリは使わず、一から書いています。サイは角の丸い立方体として、丼の曲面・卓・ほかのサイとの衝突、摩擦、跳ね返りを1秒あたり480回計算します。各面はほぼ均等に出ます（テストで1,500投）。
- **描画**：WebGLで描いています。藍に青海波（せいがいは）模様の丼、木目、サイの影、丼のふちの影はすべてシェーダーの中で作っています。画像ファイルは使っていません。
- **音**：Web Audioで合成しています。茶碗の「カラン」という音、サイ同士の音、卓に落ちる音、心音、チップの音があり、ぶつかった強さと位置で鳴り方が変わります。
- チュートリアルで特定の役を出す時は、物理で転がした結果に合わせて、サイの面の向きを入れ替えています。転がり方そのものは本物の物理計算です。

## ファイル構成

```
chinchiro/
├── index.html      ← これを開けば遊べる（下の4ファイルをまとめたもの）
├── README.md       ← この説明
└── src/            ← 改造したい人向けのソース
    ├── index.html  ← 画面のつくりとCSS
    ├── physics.js  ← 物理演算
    ├── gfx.js      ← WebGLの描画
    ├── audio.js    ← 効果音の合成
    ├── game.js     ← ルール・モード・画面
    └── build.py    ← src を1つの index.html にまとめる
```

`src` を改造したら、`src` フォルダの中で `python3 build.py` を実行すると `index.html` が作り直されます。

## スマホ向けの調整（お店に置くときに追加）

- 縦長の画面では、上の座席札と下の操作盤のあいだに丼が来るよう、カメラの見る点を手前にずらして少し寄る（視点を回しても同じ）。
- 「振る」ボタンを1行の大きな文字にし、ゲージに「弱」「強すぎ」の目印をつけた。長押しでスマホのメニューや文字選択が出ないようにした。
- せまい画面では座席札の名前を短くする（慎重なタケ → タケ）。小さい画面（iPhone SE など）ではタイトルのモード一覧を詰める。
- 投げた瞬間に軽く振動する（対応している端末だけ）。

## 動作環境

- WebGLが使えるブラウザが必要です（最近のスマホ・PCならほぼ使えます）。
- スマホでもPCでも遊べます。スマホは縦持ちに合わせて作っています。
- 振動の演出は、Androidの一部のブラウザでしか動きません。

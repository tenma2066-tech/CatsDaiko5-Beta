やり方

  1. App Store で Orion Browser（無料）を入れる
  2. Orion の拡張機能から Cookie-Editor を入れる
  3. Orion で x.com を開き、いつも通り自分でログイン
  4. x.com を開いたまま Cookie-Editor を開き、Export → JSON でコピー（または auth_token と ct0 の値だけコピー）
  5. 下に貼り付けて「取り込む」
この値はパスワードと同じくらい大事です。チャットや他の人には見せないでください。X でログアウトすると無効になります。
